# WASHIFYY – UI/UX Design Project

## Project Overview
Washifyy is a laundry and garment-care service application designed to make laundry booking and management easier and more convenient.

## Project Objective
To create a simple and user-friendly experience for customers to select laundry services, schedule pickups, make payments and track their orders.

## My Role
UI/UX Designer

## Tools Used
- Figma
- User Flow Diagrams
- Wireframing
- Prototyping
- User Research

## Key Features
- User registration and login
- Laundry service selection
- Pickup scheduling
- Online payment
- Order tracking
- Order cancellation and alternative flows
